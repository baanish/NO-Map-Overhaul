# Baanish UI Improvements v0.1.0

The first release of my map and HUD navigation mod. It covers runway markers and an optional airbase boundary. The other planned features are [coming soon](../../README.md#coming-soon).

## Included

- **Runways on the map.** Every friendly runway appears on the minimap and full map, numbered at each end. The numbers come from the runway heading, like the game's landing clearance, with the paint winning where the two differ.
- **Approach line.** Within 5 km, a dashed 5 km centerline extends off the nearest runway end, to judge the turn onto final. Each dash plus gap is 500 m.
- **HUD callout.** A `RWY 27` label sits over that end's threshold, ready for an ATC call. Turn on **IncludeAirbaseName** for `NBSCLI RWY 27`.
- **Airbase boundary**, off by default. A faint circle marks each friendly airbase's landing zone, where a stopped aircraft counts as returned. It is also the capture zone.
- **Settings.** Visibility, colours, sizes, range, and line length can all be changed live with F1.

Helicopters see only the airbase boundary, and carriers are left out.

## Test status

- 9 automated tests pass for runway-end selection and naming.
- Tested in single-player free flight at North Boscali, Feldspar, and Opal on Nuclear Option 0.34.2 (Steam build 24724372) with BepInEx 5.4.23.4.
- A multiplayer session showed no problems. The mod only draws and sends nothing over the network.

## Downloads

- `BaanishUiImprovements-v0.1.0-nomm.zip` is the flat package for Nuclear Option Mod Manager.
- `BaanishUiImprovements-v0.1.0-plugin-only.zip` can be extracted beside `NuclearOption.exe` when BepInEx 5 is installed.
- `SHA256SUMS.txt` lists both archive checksums.

Configuration Manager isn't bundled. Install it separately to use F1.
