# NO Map Overhaul v0.5.0

Baanish UI Improvements is now **NO Map Overhaul**, a map mod with planning tools on the full map. Its missile arrows moved to their own mod, [NO Missile Indicators](https://github.com/baanish/NO-Missile-Indicators), because they're a HUD combat aid rather than a map feature.

## New: map tools

Press `H` on the full map to open the tool rail, and `1` to `6` to pick a tool. The [map tools guide](../MAP_TOOLS.md) covers them all.

- **Bearing and range:** an arrow with a BRA label, such as `045° 12nm 18k ft`, with straight-line range and the contact's altitude. Pin either end to a unit and it follows. Double-tap `1` to measure from your own aircraft.
- **Range circles:** any size, or the 5, 10, and 20 presets. They also show as rings in the 3D view.
- **Text notes:** click a contact to tag it. The note follows the contact and goes away when it's killed.
- **Pen**, **waypoint routes** with the next two waypoints labelled in the 3D view, and the **eraser**, undo, redo, and clear. Right click deletes a drawing or cancels one in progress.
- **Fair play:** drawings on other units use your side's tracks, and freeze and read `lost` when a track goes stale.

## Changed

- **Settings** carry over from Baanish UI Improvements. F1 groups them into ordered sections, with tuning knobs behind "Advanced settings".
- **Airbase names** show your own side's airbases only, including captured and mission-added ones.

## Upgrading

Delete `BepInEx/plugins/BaanishUiImprovements` when you install this. If you leave it, NO Map Overhaul switches it off and logs which folder to delete. The [install guide](../INSTALL.md) covers a fresh install and upgrading.

## Test status

- 155 automated tests pass.
- Checked in game on Nuclear Option 0.34.2 with BepInEx 5.4.23.4, in single-player missions: every map tool, the upgrade from Baanish UI Improvements, and the perf test. With no drawings the mod costs about 1% of the frame rate, and about 6% with a typical set of drawings on the minimap.
- The map tools haven't been flown in multiplayer yet.

Full record: [testing](../TESTING.md).
