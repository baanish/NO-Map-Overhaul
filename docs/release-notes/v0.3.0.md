# Baanish UI Improvements v0.3.0

Adds two settings: one hides the HUD runway callout until your gear is down, and one turns the whole mod off without uninstalling it. The other planned features are [coming soon](../../README.md#coming-soon).

## New

- **Callout with the gear down only**, off by default. Turn on **HUD → OnlyWithGearDown** and the `RWY 27` label shows only while your landing gear is down. It appears as soon as you lower the gear lever.
- **Master switch.** Turn off **General → Enabled** to hide everything the mod draws, as if it were not installed. Use it to check whether a problem comes from the mod or the game, without restarting.

## Test status

- 9 automated tests pass for runway-end selection and naming.
- Both settings were checked in single-player free flight on Nuclear Option 0.34.2 with BepInEx 5.4.23.4.

Full record: [testing](../TESTING.md).

## Downloads

- `BaanishUiImprovements-v0.3.0-plugin-only.zip` can be extracted beside `NuclearOption.exe` when BepInEx 5 is installed.
- `SHA256SUMS.txt` lists both archive checksums.

Configuration Manager isn't bundled. Install it separately to use F1.
