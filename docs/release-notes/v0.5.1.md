# NO Map Overhaul v0.5.1

Map labels now stay out of the clutter as you zoom the full map.

## Changed

- **Airbase names** move down to the edge of the airbase's capture circle as you zoom in, so they sit below the base's units instead of on top of them.
- **Runway numbers** on the full map all hide together once you zoom far out, so they don't pile onto the airbases. The minimap always shows them. To change the cutoff, turn on "Advanced settings" in F1 and set Map / Runways → Numbers from zoom; 0 always shows them.

## Upgrading

Install over 0.5.0. Settings carry over.
