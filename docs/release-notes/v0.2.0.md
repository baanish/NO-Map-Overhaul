# Baanish UI Improvements v0.2.0

Adds airbase names to the full map, so a base someone calls out on comms is easy to find. The other planned features are [coming soon](../../README.md#coming-soon).

## New

- **Airbase names**, off by default. Turn on **Airbase Names → ShowNames** and every airbase, friendly, enemy, and neutral, gets its name just under it on the full map. The game draws no icon for enemy or neutral airbases, so this is the only marker they get. Airbases sharing a name, like the three Feldspars in Ignus free flight, get one label.
- **Map text rim.** Runway numbers and airbase names have a thin dark rim, so they stay readable over the map's green linework at a smaller size.

## Changed

- Runway numbers default to size 8, down from 13. If you never changed the size, delete `RunwayLabelSize` from the settings file to pick up the new default, since BepInEx keeps saved values.

## Test status

- 9 automated tests pass for runway-end selection and naming.
- Airbase names and the text rim were checked in single-player free flight on Ignus (Feldspar) and at Opal, on Nuclear Option 0.34.2 with BepInEx 5.4.23.4.

Full record: [testing](../TESTING.md).
