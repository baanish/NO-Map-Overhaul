# Baanish UI Improvements v0.4.0

Adds missile arrows, so a missile fired from outside your view is easy to find and shoot down. Waypoints and map drawing are [coming soon](../../README.md#coming-soon).

## New

- **Missile arrows**, on by default. Each incoming missile outside your view gets a red arrow on the screen edge, pointing the way to turn toward it. A missile behind you gets its arrow on the side it's on. The arrow goes once the missile is on screen. Turn them off with **Missile Arrows → ShowArrows**, or change **Missile Arrows → Color**.
- Only missiles the game's missile warning already knows about get an arrow, so the arrows show nothing the game hasn't told you. They work in every aircraft, helicopters included.
